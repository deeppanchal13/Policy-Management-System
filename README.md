# 🛡️ Insurance Policy Management System

A menu-driven **C++ project** to manage customers and insurance policies using basic programming concepts and file handling.

## ✨ Features
- Add and view customers
- Create and view insurance policies
- Support for Life, Health, Vehicle, and Property insurance
- Calculate insurance premiums
- Search policies by ID
- Store records using text files

## 🛠️ Technologies
- C++
- Structures, Functions & Arrays
- File Handling (`fstream`)

## 🚀 How to Run

Compile:
```bash
g++ main.cpp -o insurance
```

Run on Windows:
```bash
insurance.exe
```
